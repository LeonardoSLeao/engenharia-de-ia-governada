# Fichas de leitura

Fichas estruturadas de artigos seminais de IA generativa, lidas no original e escritas em português. O modelo usado em todas está em [`_template.md`](_template.md).

O critério das fichas é o mesmo do resto do repositório: descrever o mecanismo com precisão suficiente para explicá-lo num quadro branco, e terminar sempre pela pergunta que importa — o que isso muda numa decisão real de arquitetura, custo, avaliação ou risco.

Os artigos abaixo formam o núcleo. Cada um vira link assim que a ficha correspondente é publicada.
